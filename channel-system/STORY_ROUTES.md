# Story routes

Twelve ways to organise a money story so that each beat makes the next one necessary. Pick one route as the backbone of an episode before writing; the format book's rhythm rules (skits, cards, pace) then sit on top of it.

How to use it:
1. Write the promise first (FORMAT_BOOK 4, "The promise and the chain"): the question, the short answer, the chain.
2. Pick the route whose "use when" matches the story. Do not pick by which opening sounds loudest.
3. A route is a skeleton, not wording. Write every line new. If no route fits the evidence, build a new one and add it here.
4. Whatever the opening promises, the ending pays: a deadline needs the state at the deadline, a comparison needs the same measure on both sides, a "who paid" needs a named payer.

These are editorial tools drawn from how good explainers are built. They are not measured formulas and promise no views.

| # | Route | Use when | The chain | The ending owes the viewer |
|---|---|---|---|---|
| 1 | **Follow one object** | A flow of money can be traced through a single thing: one banknote, one share, one mortgage, one barrel | Start with the object in the viewer's hand → each stop takes or adds something, with the rule that allows it → what is left, and who holds it | What reached the end, and how typical this one object is |
| 2 | **Work backward from the wreck** | Something visible just happened: a crash, a collapse, a record fine | The scene today → its immediate cause → the earlier decision behind that → replay it forward → the weakest link | Which link, if removed, changes the outcome |
| 3 | **The hidden cost** | Something looks free, cheap or generous | The obvious benefit → the mechanism that pays for it → who carries that cost → benefit and cost on the same scale | Whether it is still worth it, and for whom |
| 4 | **Pull out one support** | A system quietly depends on one input: cheap credit, one supplier, one customer, one rule | Normal operation → remove the input → the first function to fail → what fails because of that → what keeps working, and for how long | What the system actually depended on |
| 5 | **The loop that feeds itself** | A rise or a fall accelerates: a bubble, a bank run, a margin spiral | The first push → how the result becomes the next cause → why it is a loop and not a line → what limits it | What stops the loop, or what stopped it |
| 6 | **The bottleneck** | A big plan is limited by one scarce thing: power, chips, permits, people, time | The goal and its scale → what it needs → what exists → the one shortage → the workaround and its own limit | How far the plan gets under that limit |
| 7 | **The fix that moved the problem** | A rescue, a rule or a clever product made one thing better | The original problem → the fix → where the risk or cost went → compare the total before and after | Whether the problem shrank or just changed address |
| 8 | **One shock, different kitchens** | The same event lands differently on different people: a rate change, a tariff, inflation | The shared shock → person A → person B on the same measure → an edge case → what decides the difference | The one factor that sorts winners from losers |
| 9 | **The obvious answer, tested** | Most viewers already believe a simple explanation | State the common belief fairly → check the assumption under it → the piece it leaves out → both predictions side by side | The explanation that survives, without mocking the first one |
| 10 | **Two true statements** | The record and the feeling disagree: record profits and layoffs, a strong economy and angry voters | Both claims with their sources → what each one is actually measuring → rebuild the picture with both | Which statement answers which question |
| 11 | **The clock** | The drama happened in hours: an earnings call, a bank weekend, a flash crash | Before the bell → each decision at its time → what could not be done in the time left | The state at the last bell, and what stayed unresolved |
| 12 | **The spreading stain** | Trouble starts in one corner and travels: contagion, supply chains, a default | The first failure → who was directly connected → where it grew and where it was contained → the firewall | How far it reached, and what stopped it |

## Checks before the script goes on

- Can every chapter change be said with "because", "so", "but" or "unless"? If it only works as "and here is another fact", move it or cut it.
- Is the short answer given early? A viewer who knows the outcome stays to learn how it was possible. Holding back a simple answer to stretch the suspense loses them.
- Does one comparison per big number use the same units on both sides (dollars with dollars, per year with per year)?
- Where does the evidence stop? An allegation, a model or a forecast is part of the answer, said as clearly as the claim.
- Is the opening's question the one the ending answers, in nearly the same words?
