# Engine requests, 13 Nov 2026: adult cast, bodies that act, places with depth

From the user's verdict on Poppi (13 Nov 2026): the characters are too simple and read as a children's cartoon; figures stand while the camera moves; frames are empty; backgrounds are a few flat shapes; every shot has the same dark-with-one-spotlight look. Measured on Poppi's 271 scenes: only the camera moves in 156 (lint G7: 34%), one figure or one prop in 137 (G8: 51%), only living things in 109 (G9: 41%), dark 100% (D1). The rules are in FORMAT_BOOK 11 and STYLE_GUIDE (Figures; Sets and props). Everything stays drawn in code (no painted figures, decision of 13 Nov).

Order of work: 1, then show the user, then 2, 3, 4.

1. **Rig v2: the cast as adults** (`studio/engine/rig.js`). Head about a third of the height, a neck, shoulders; arms with elbows and hands with four fingers and a thumb that grip props (no floating mittens); body shapes that differ by person (tall, broad, slight); faces with a jaw and cheek shape, ears, a nose of their own, hair with volume; two tones on skin and clothes (shadow side) and varying line weight; clothes with collars, seams, pockets, buttons. Keep every name, face, pose and prop of the current rig working (the storyboards of both episodes must still build), the signature colours and props in `cast.md`, mouths that move with the words, blinks and breathing. Redraw `channel-system/characters/sheets/` (`node studio/tools/stills.mjs sheets`) and **stop: the user approves `cast_lineup.png` before anything else is built on it.** Guest caricatures and background figures use the same skeleton.
2. **A body that acts.** A walk cycle with legs and swinging arms for `"to"`; new acts that use the arms: `reach`, `handover` (a prop passes from one figure's hand to another's), `sit`, `stand`, `turn` (back to camera), `lean`, `slam` (hands on a table); idle weight shifts. Entrances by default where the storyboard gives none (`enter` walks in from the nearer edge).
3. **Places with depth** (`studio/engine/sets.js`). Every set gets a foreground layer the camera passes, a back wall with eight or more objects that say where we are, and one living detail (passer-by, steam, flickering screen, traffic). Helpers for the detail (shelf with items, framed picture, plant, cable run, window with a view) so a set stays cheap to write. Every set has a day look and a `night` look. Start with the sets Poppi used most: `pitch_stage`, `night_office`, `kitchen`, `supermarket`, `bank`, `back_shop`, `desk_top`, `boardroom`.
4. **More kinds of light.** Besides the spotlight `"light"`: a window (a soft slanted rectangle of light), a screen glow (cold, low, from below), neon (coloured, two sources), daylight (no vignette, warm). One storyboard key, e.g. `"light": { "kind": "window" }`, backwards compatible.

Done means: the gallery shows every new piece; the user approved the cast line-up; `npm run check` passes; both episodes still build; on the gallery the lint's G7 and G8 pass.
