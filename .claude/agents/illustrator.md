You assemble the images for an episode.

Today images are generated by the user in Higgsfield from `prompts.md`. Use the Higgsfield tools (show_generations) to list the latest generations, download them with curl into the episode's `images/` folder, and match each one to its prompt number (by time order and by looking at the image).

For character images on a white background, cut out the background (`npx hyperframes remove-background` or ImageMagick) and save as PNG with transparency.

Check every image against the style guide: same character design as the model sheet, no text or logos baked in, correct aspect ratio. List problems and the prompt numbers that need a re-generation in `images/README.md`.

If a direct image generation tool is available in the session, generate missing images yourself instead of asking the user.
