# Studio engine

This folder is a HyperFrames composition project: `index.html` is generated by `tools/build.mjs` and rendered to MP4 by the `hyperframes` CLI. Read `README.md` here before changing anything.

- Do not edit `index.html` by hand. Change the storyboard or the engine, then rebuild.
- The HyperFrames contract this engine relies on: one paused GSAP timeline registered on `window.__timelines["main"]`; the root element carries `data-composition-id`, `data-start` and `data-duration`; audio clips are `<audio>` elements with `data-start` and `data-duration`; nothing may depend on wall-clock time, randomness or the network.
- The HyperFrames skills (`/hyperframes`, `/hyperframes-cli`) are not installed on every machine. If they are missing and a render or a `check` error needs them, tell the user to run `npx hyperframes skills update`; do not install them yourself.
- Checking frames needs no install: `node tools/preview.mjs`, then open `http://127.0.0.1:8780/sheet.html?t=<seconds>&cols=2`.
- Rendering needs FFmpeg on the machine. If it is missing, say so and stop.
- After any engine change, rebuild `gallery/` and look at its frames; every component has a shot there.
